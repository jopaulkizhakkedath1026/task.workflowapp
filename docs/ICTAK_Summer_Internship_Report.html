Executive Summary

This report documents the internship activities, technical architecture, implementation, and deliverables accomplished during the Summer Internship in Full Stack Application Development with ReactJS conducted by the Information & Communication Technology Academy of Kerala (ICTAK).

The primary project centered on developing the backend services and integrating the responsive Single Page Application (SPA) for the Employee Management Portal using the MERN stack (MongoDB, Express.js, React.js, and Node.js). Key outcomes include provisioning a resilient cloud NoSQL database via MongoDB Atlas, constructing standardized RESTful CRUD APIs with validation and error-handling middleware, and serving production-optimized client assets seamlessly.

Introduction

Modern web engineering prioritizes decoupled, event-driven, scalable architectures. The ICTAK Full Stack Internship program provided an immersive experience bridging theoretical concepts in client-side ReactJS and server-side Node/Express development with practical, industry-grade implementation.

The project provides an intuitive corporate staff directory where organizations can register employees, review profiles by ID, revise role/compensation attributes, and delete decommissioned records in real time.

Objectives

  • Implement a complete RESTful API supporting standard HTTP methods (GET, POST, PUT, DELETE).
  • Model workforce data schemas using Mongoose ODM connected to a remote MongoDB Atlas cluster.
  • Establish secure application middleware, including CORS, body parsing, and request logging.
  • Integrate pre-compiled React frontend client assets with the Express web server.
  • Perform rigorous API functional testing and end-to-end user journey verification using Postman and browser DevTools.

Scope and Deliverables

Scope: Complete backend integration of the Employee App, including MongoDB Atlas database connection, Express routing for five RESTful endpoints, static delivery of client build files, and comprehensive testing.

Deliverables:

  • Production backend source code (app.js and model/employeeList.js).
  • Software Requirements Specification (SRS) documentation.
  • Complete API test suite evidence.
  • Formal Summer Internship Final Report.

Methodology

The project adhered to an iterative Agile life cycle divided into key phases: requirement analysis, Mongoose schema modeling, REST route development, middleware integration, error handling, and verification.

Project Activities

  1. Project & Dependency Setup: Initialized npm package with Express, Mongoose, Dotenv, Cors, and Morgan.
  2. Database Connection: Configured MongoDB Atlas cluster and authenticated via Mongoose connection URI.
  3. Schema Design: Implemented employeeSchema enforcing mandatory constraints on name, location, position, and salary.
  4. CRUD API Implementation: Constructed routes for retrieving all records, single record lookups, record insertion, record editing, and record removal.
  5. Static Asset Serving: Linked dist/Frontend build output to serve the responsive UI across desktop and mobile devices.

// RESTful Endpoint for Employee Listing
app.get("/api/employeelist", async (req, res) => {
  try {
    const data = await employeeModel.find();
    res.json(data);
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});

// RESTful Endpoint for New Employee Creation
app.post("/api/employeelist", async (req, res) => {
  try {
    const data = new employeeModel(req.body);
    const doc = await data.save();
    res.status(201).json(doc);
  } catch (err) {
    res.status(400).json({ error: err.message });
  }
});
